# Public Synthetic Corpus

Generated by `pnpm corpus:public`. Do not edit these files by hand.

The corpus exercises package specifications and bodies, nested blocks, CASE
expressions, cursors, loops, exceptions, conditional compilation, declaration
sections that start a body after local declarations, bare `JOIN` without a first
table alias, and alternative-quoted strings. It contains no production source
and no confidential identifiers.

Regenerate and verify:

```bash
pnpm corpus:public
pnpm test
```

The corpus is deliberately small. It is suitable for smoke tests and harness
validation, not for production performance claims.
